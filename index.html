این سؤال‌ها رو دوباره مرور کن:

    ویرایش آزمون

    برای ویرایش نسخه‌ی اصلی، «رمز ویرایش» لازمه. این رمز یه توکن گیت‌هابه که فقط تو داری. فقط یک بار می‌سازیش:

    1. وارد github.com شو و از منوی پروفایل بزن: Settings
    2. پایین منو: Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token
    3. Repository access: «Only select repositories» و فقط مخزن همین بازی رو انتخاب کن
    4. Permissions ← Repository permissions ← Contents: «Read and write»
    5. بساز و کدی که نشون می‌ده رو همین‌جا بچسبون (بعداً دیگه نشون داده نمی‌شه)

    برای هر سؤال، دایره‌ی کنار جواب درست رو انتخاب کن. گزینه‌ی خالی نادیده گرفته می‌شه (حداقل ۲ گزینه لازمه). با «ذخیره در نسخه اصلی» تغییرها برای همه‌ی بازیکن‌ها اعمال می‌شه؛ ممکنه چند دقیقه طول بکشه تا برسه.
