      🏆 جدول برتر این دستگاه

        مدیریت درس‌ها

        برای ویرایش، «رمز ویرایش» لازمه. این رمز یه توکن گیت‌هابه که فقط تو داری و فقط یک بار می‌سازیش:

        1. وارد github.com شو و از منوی پروفایل بزن: Settings
        2. پایین منو: Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token
        3. Repository access: «Only select repositories» و فقط مخزن همین بازی رو انتخاب کن
        4. Permissions ← Add permissions ← Contents ← «Read and write»
        5. بساز و کدی که نشون می‌ده رو همین‌جا بچسبون (بعداً دیگه نشون داده نمی‌شه)

        هر درس یه لینک مخصوص خودش داره. بعد از هر تغییر (درس جدید، حذف یا ویرایش) حتماً «ذخیره‌ی همه در نسخه اصلی» رو بزن؛ لینک درس‌های جدید هم بعد از ذخیره کار می‌کنه.

        کلمه‌ها رو بنویس. توی حالت «با صدا» برای هر کلمه صدا ضبط کن (🎤) یا فایل صوتی انتخاب کن (📁)؛ بچه فقط صدا رو می‌شنوه و باید حروف رو درست بچینه. توی حالت «حروف به‌هم‌ریخته» صدا لازم نیست.

        برای هر سؤال، دایره‌ی کنار جواب درست رو انتخاب کن. هر گزینه یا متنه یا تصویر: با دکمه‌ی 🖼️ تصویر بذار و با ✕ برش گردون. گزینه‌ی خالی نادیده گرفته می‌شه (حداقل ۲ گزینه لازمه).
